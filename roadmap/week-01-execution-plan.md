# Week 01：Agent 基础与最小主持人 - 可执行计划

> 建议周期：2026-08-03（周一）至 2026-08-09（周日）  
> 总投入：约 8 小时  
> 本周目标：理解 **Agent = LLM + 上下文 + 工具**、ReAct、Harness 与护栏；创建 AI 剧本杀主持人的最小 FastAPI 骨架。

## 本周完成定义

到周日结束时，必须同时完成：

- [ ] 用自己的话写出 LLM、上下文、工具、Harness 各自负责什么；
- [ ] 画出一次“玩家行动 → 主持人 → 候选事件”的数据流；
- [ ] 在 `projects/murder-mystery-host/` 建好最小 Python/FastAPI 项目；
- [ ] 有 `Scenario`、`Character`、`GameState`、`Event` 四个最小数据模型；
- [ ] `POST /rooms` 和 `POST /rooms/{id}/actions` 可返回模拟的候选事件；
- [ ] 写出一篇 Week 01 笔记，记录至少一个失败/不确定点。
