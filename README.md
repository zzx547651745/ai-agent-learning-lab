# AI Agent Learning Lab

一个面向工程实践的 AI Agent 学习仓库。学习主线参考《深入理解 AI Agent：设计原理与工程实践》，将每周的概念、实验、失败案例与项目代码沉淀为可复现的公开材料。

当前贯穿项目是 **AI 剧本杀主持人**：一个强调权限隔离、状态机、RAG、工具运行时、评测与可观测性的多 Agent 应用。

## 学习路线

| 阶段 | 周次 | 主题 | 项目产出 |
| --- | --- | --- | --- |
| Agent 工程底座 | 1–6 | Agent、上下文、记忆/RAG、工具、Coding Agent | 可运行的文字主持人与规则引擎 |
| 质量与进化 | 7–10 | Eval、后训练决策、持续进化、多模态 | Eval 集、失败复盘与可选语音原型 |
| 协作与平台化 | 11–14 | 多 Agent、深度研究、剧本工坊、生产交付 | 可回放、可部署的 v0.1.0 |

学习路线提供两个视图：

- [14 周总览](roadmap/14-week-plan.md)：便于快速查看每周主题和产出；
- [14 周详细执行计划](roadmap/14-week-plan-detailed.md)：包含书中知识点、实战增量、验收标准、仓库骨架与项目安全边界。

## 每周工作流

| 时间 | 目标 | 最低产出 |
| --- | --- | --- |
| 周一 | 阅读主题并完成最小实验 | 笔记草稿与实验记录 |
| 周四 | 深化难点并推进项目模块 | 代码、测试或 Eval 用例 |
| 周六 | 完成功能与收集复盘素材 | 可运行功能和失败案例 |
| 周日 | 补位学习并收尾 | 一篇完整周笔记 |
| 下周一 | 审阅并准备公众号文章 | 可发布草稿；人工确认后发布 |
